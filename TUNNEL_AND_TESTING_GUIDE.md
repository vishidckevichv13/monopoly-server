# Инструкция по локальному запуску и тестированию в Telegram на смартфоне

Проект готов к запуску и тестированию как в обычном браузере, так и на мобильном устройстве через Telegram Web App.

---

## 1. Запуск на локальном ПК

### Одновременный запуск сервера и клиента:
В корневой директории проекта выполните:
```bash
npm run build --workspaces
npm run dev:server
```
И во втором терминале:
```bash
npm run dev:client
```
- **Клиент (Frontend)** запустится на: `http://localhost:3000`
- **Сервер (Backend & WebSocket)** запустится на: `http://localhost:4000`

---

## 2. Подключение Telegram со смартфона (Туннель)

Telegram Mini App требует обязательного HTTPS протокола. Чтобы Telegram мог открывать игру с вашего домашнего ПК:

### Вариант А: Через Cloudflare Tunnels (Бесплатно, без регистрации)
1. Скачайте `cloudflared` для Windows (или установите через `winget install Cloudflare.cloudflared`).
2. В командной строке выполните:
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
3. Cloudflare сгенерирует для вас публичную ссылку вида: `https://xxxx-xxxx.trycloudflare.com`.

### Вариант Б: Через ngrok (Популярный сервис)
1. Установите `ngrok` и выполните:
   ```bash
   ngrok http 3000
   ```
2. Скопируйте полученную ссылку `https://xxxx.ngrok-free.app`.

---

## 3. Подключение к боту в Telegram

1. Откройте `@BotFather` в Telegram.
2. Выберите вашего бота или создайте нового (`/newbot`).
3. Выполните команду `/setmenubutton` -> выберите бота -> укажите сгенерированную HTTPS ссылку и название кнопки (например, `🎲 Играть в Монополию`).
4. Откройте бота со своего смартфона и нажмите на кнопку меню!

---

## 4. Что уже реализовано в MVP

1. **2.5D Мобильная доска**: Оптимизирована для вертикальных экранов 9:16/9:19 с изометрической перспективой.
2. **Authoritative Game Engine**:
   - 40 игровых клеток (улицы, ж/д, коммуналки, налоги, тюрьма, шанс, казна).
   - Броски кубиков (с определением дублей и отправкой в тюрьму за 3 дубля).
   - Покупка предприятий, автоматический расчет аренды с учетом монополий и филиалов.
   - Постройка филиалов и отелей.
   - Джекпот на бесплатной стоянке.
3. **Мультиплеер и Боты**:
   - Создание комнат и вход по ID / ссылке.
   - Поддержка AI ботов (бот сам бросает кубики, покупает карточки, развивает монополии).
   - Таймер хода (30 сек) с авто-ходом при таймауте.
4. **Telegram Mini App UX**:
   - Полноэкранный режим (`WebApp.expand()`).
   - Telegram Haptic Feedback (вибрация при броске, покупке, выигрыше).
   - Автоматическая подгрузка Telegram аватара и никнейма.
